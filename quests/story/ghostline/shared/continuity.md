# Ghostline Continuity

## Canonical Order

1. `gq001` replaces the `gq000` prototype as V's first Ghostline job. V meets
   Patch, extracts the Quiet Spine cache, brings it to Iris, and completes the
   handoff.
2. `gq002`, The Machine Stops, exposes and disables or spoofs the Kabuki tenant
   classifier used to select low-visibility targets.
3. `gq003`, Black Lantern, begins after Iris reconstructs the `gq001` cache.
   The `gq002` shutdown forces Pair 07 into an expedited handoff.

`gq000` is implementation history, not an additional event in the story.

Quest-local continuity documents own outgoing branches. This file records only
facts and ordering shared by later quests.
