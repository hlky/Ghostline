# Story Quests

Story documentation is grouped first by series and then by stable quest ID.

## Series

- [Ghostline](ghostline/README.md) — a connected sequence about Ghostline,
  Quiet Spine, Common Ground, and the stolen-identity courier network.

Quest folders own narrative design, exact script text, authoring manifests, and
implementation notes. Game-ready and editable WolvenKit resources remain under
`source/archive`, `source/raw`, and `source/resources`.
