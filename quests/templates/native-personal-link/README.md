# Native meeting and personal-link template

Start from [template.json](template.json) and follow the
[authoring guide](../../../docs/authoring/native-quest-template.md) to generate
an isolated native meeting/transfer/reward/completion preview.

The generic builders are extracted from GQ004; the seven original graphs are
pinned in [gq004-graph-baseline.json](gq004-graph-baseline.json). New bindings
still require world, scene, character and item integration and an in-game pass.
