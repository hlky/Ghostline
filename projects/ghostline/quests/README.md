# Ghostline

Ghostline is a connected Cyberpunk 2077 quest series about a covert broker
collective uncovering the Quiet Spine identity-laundering network.

## Quest Order

| Quest | Title | Series status |
| --- | --- | --- |
| [`gq000`](gq000/README.md) | Original Ghostline prototype | Superseded runtime baseline |
| [`gq001`](gq001/README.md) | Ghostline | First canonical quest; extends and replaces `gq000` |
| [`gq002`](gq002/README.md) | The Machine Stops | Canonical |
| [`gq003`](gq003/README.md) | Black Lantern | Canonical preproduction |

`gq000` remains important because later quest specs reuse its validated phases,
scene, and world resources as templates. In story continuity, however, `gq001`
is the first completed job: it adds the Iris handoff to the original
Patch/cache/delivery route.
